إعدادات التواصل ورقم الواتساب الافتراضي

تحديث رقم الواتساب يغيره تلقائياً في كافة أزرار الموقع والصفحات.

مثال للسعودية: 966501234567 أو 966551234567
🎁

نظام الخصم والتخفيض التلقائي للسلة (Threshold Discount)

تطبيق تخفيض فوري للزبونة عند وصول مجموع السلة لقيمة يحددها مدير لوحة التحكم.

مثلاً: 5000 ريال سعودي
إذا نسبة أدخلي: 15 (يعني 15%)، إذا مبلغ: 500
يتم استبدال {remaining} تلقائياً بالمبلغ المتبقي، و {discount} بقيمة الخصم.
🔥

إدارة وربط قاعدة بيانات Firebase Firestore

مزامنة سحابية فورية لكافة الفساتين والطلبات والإعدادات عبر السحابة مع دعم التخزين المحلي الآمن.

جاري التحقق من الحالة...

مفاتيح الربط لمشروع Firebase:

🛡️ قواعد أمان Firestore Database (Security Rules) وطريقة تفعيلها عرض القواعد 📋

لتشغيل قاعدة البيانات دون أي رفض للصلاحيات، تأكدي من وضع القواعد التالية في تبويب Rules داخل مشروع Firebase:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

تم حفظ ملف القواعد أيضاً في جذر المشروع باسم firestore.rules.
