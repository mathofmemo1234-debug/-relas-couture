# 👗 ريلاس لفساتين السهرة والزفاف | Relas Couture

موقع إلكتروني فاخر لدار **ريلاس للأزياء الراقية (Relas Couture)** في الرياض، مصمم بنمط دار الأزياء العالمية **روزا كلارا (Rosa Clara)**، ويتضمن استوديو أخذ قياسات تفاعلي ذكي، لوحة تحكم شاملة، ربط مباشر بالواتساب، ودعم سحابي لقاعدة بيانات Firebase Firestore مع إمكانية النشر الفوري على GitHub Pages.

---

## ✨ المميزات الرئيسية

- 💎 **تصميم روزا كلارا الفاخر (Haute Couture Aesthetic)**: خطوط طبوغرافية أنيقة، ألوان العاجي والذهب والأسود الملكي، بطاقات فساتين متجاوبة مع محاكي تقسيط تابي وتمارا.
- 📐 **استوديو أخذ القياسات التفاعلي (13 نقطة قياس)**: مانيكان تفاعلي مرقم ومستوحى من بطاقة تفصيل ريلاس للأزياء مع قوائم منسدلة وإرشادات توضيحية.
- 🖨️ **طباعة بطاقة المشغل الكلاسيكية**: بطاقة خياطة مطابقة للأصل للأتيليه والمشغل مع العبارة الشهيرة *"لكونكِ أنثى راقية تشرفنا في تصميم قطعتكِ الخاصة"*.
- 💬 **ربط واتساب ديناميكي**: إمكانية تعديل رقم الواتساب المعتمد في أي وقت من لوحة التحكم ليُطبّق على جميع أزرار الموقع فوراً.
- ⚙️ **لوحة تحكم متكاملة (Admin Dashboard)**: إدارة الفساتين، متابعة طلبات القياسات وتحديث حالاتها، إعدادات المتجر، والربط مع Firebase.
- 🔥 **تخزين مزدوج ذكي**: يعمل سحابياً عبر Firebase Firestore أو محلياً عبر LocalStorage بدون أي إعدادات معقدة.
- 🚀 **جاهز للنشر على GitHub Pages**: بدون خطوات بناء (Zero-build)، يعمل مباشرة في أي متصفح.

## 🚀 التشغيل السريع

1. افتحي ملف `index.html` في أي متصفح لتصفح المتجر.
2. افتحي ملف `measurements.html` لتجربة استوديو القياسات والمانيكان التفاعلي.
3. افتحي ملف `admin.html` للدخول إلى لوحة التحكم (كلمة المرور الافتراضية: `123456`).

للاطلاع على خطوات النشر على **GitHub Pages** وربط **Firebase**، يرجى قراءة [دليل النشر والاستضافة](DEPLOYMENT_GUIDE.md).
